# 🧞 ResumeGenie

**ResumeGenie** is a full-stack GenAI-powered job preparation platform that helps job seekers optimize their resumes, understand job requirements, close skill gaps, and prepare for interviews — all powered by Google's Gemini AI.

🔗 **Live Demo:** [resumegenie-pdq3.onrender.com](https://resumegenie-pdq3.onrender.com)

---

## ✨ Features

- 📄 **Resume Analysis** — Upload a resume and get AI-driven feedback on structure, content, and impact
- 📋 **Job Description Analysis** — Parse and analyze job postings to extract key requirements
- 🧩 **Skill-Gap Detection** — Compare your resume against a job description to identify missing skills
- ✅ **ATS-Optimized Resume Generation** — Generate resumes tuned to pass Applicant Tracking Systems
- 🎤 **AI-Powered Interview Preparation** — Practice with AI-generated interview questions tailored to a role
- 🔐 **Secure Authentication** — JWT-based auth for protected user sessions
- 🕸️ **Automated Web Data Extraction** — Puppeteer used for scraping/parsing job-related content

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [MongoDB](https://www.mongodb.com/) instance (local or Atlas)
- A [Google Gemini API key](https://ai.google.dev/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Shradha1802/ResumeGenie.git
   cd ResumeGenie
   ```

2. **Set up the Backend**
   ```bash
   cd Backend
   npm install
   ```

   Create a `.env` file inside `Backend/` with:
   ```env
   PORT=5000
   MONGODB_URI=your_mongodb_connection_string
   JWT_SECRET=your_jwt_secret
   GEMINI_API_KEY=your_gemini_api_key
   ```

   Start the backend server:
   ```bash
   npm start
   ```

3. **Set up the Frontend**
   ```bash
   cd ../Frontend
   npm install
   ```

   Create a `.env` file inside `Frontend/` with:
   ```env
   VITE_API_BASE_URL=http://localhost:5000
   ```

   Start the frontend dev server:
   ```bash
   npm run dev
   ```

4. Visit **`http://localhost:5173`** (or your configured port) in your browser.

## 🖥️ Usage

1. **Sign up / Log in** to your account.
2. **Upload your resume** to receive AI-generated analysis and improvement suggestions.
3. **Paste a job description** to get a skill-gap comparison against your resume.
4. **Generate an ATS-optimized version** of your resume for a specific role.
5. **Practice interview questions** generated by AI based on the target job.
